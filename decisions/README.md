# Architecture Decision Records

This directory contains Architecture Decision Records (ADRs) documenting significant technical decisions for the platform.

## Process

1. Before creating an ADR, ensure relevant research exists in this repository
2. Copy `ADR-000-template.md` to `ADR-NNN-short-title.md`
3. Fill in all sections — do not leave sections blank
4. Submit for review
5. Update status as decisions evolve

## Rules

- No infrastructure technology becomes foundational merely because it looked attractive in one repository
- Every ADR must reference the research that informed it
- License implications must be explicitly stated
- Reversibility must be honestly assessed
