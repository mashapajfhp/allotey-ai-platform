# Safe to Study

> STATUS: INITIAL REVIEW COMPLETE
> Last updated: 2026-08-13

All repositories in this research project are safe to study for architectural research purposes. Studying code, reading documentation, and analyzing architecture does not create license obligations.

**Every repository listed in this research project is safe to study.**

The distinction matters when moving from study to use:

| Activity | License Risk |
|----------|-------------|
| Reading source code | None |
| Studying architecture | None |
| Writing about concepts learned | None |
| Implementing similar concepts independently | None |
| Copying code verbatim | Depends on license |
| Using as a dependency | Depends on license |
| Modifying and distributing | Depends on license |

See `licensing-matrix.md` for per-repository details on what is safe beyond study.
